# ระบบประเมินสภาพบ้านก่อนรีโนเวท

เว็บแอปช่วยตรวจสภาพบ้านก่อนรีโนเวท ให้ระดับความรุนแรงรายการละหมวด ประเมินค่าซ่อม จัดลำดับงานเป็นระยะ และสรุปผลเทียบกับงบประมาณ

## ผู้ใช้
- ผู้ใช้หลัก: เจ้าของบ้านที่กำลังจะรีโนเวท (เป็นสมมติฐานของผู้พัฒนา)
- ผู้ใช้รอง: ผู้รับเหมา/สถาปนิกที่สำรวจเบื้องต้นให้ลูกค้า
- ผู้ประเมินคือผู้ใช้ระบบเอง ระบบคำนวณคะแนนจากข้อมูลที่ผู้ตรวจกรอกเท่านั้น

## ฟีเจอร์
- เข้าสู่ระบบ/ออกจากระบบ (โหมดเครื่องนี้: กรอกชื่อ ข้อมูลเก็บใน localStorage ของเบราว์เซอร์)
- หลายโครงการ: สร้าง เปิด ทำสำเนา ลบ
- รายการตรวจ 38 รายการ ใน 8 หมวด เพิ่มรายการเองได้ ค้นหาและกรองได้
- ระดับ: ดี / เล็กน้อย / ต้องซ่อม / วิกฤต / ไม่มี พร้อมบันทึก ค่าซ่อม ห้อง/พื้นที่ และรูปถ่าย (สูงสุด 4 รูปต่อรายการ)
- หน้าสรุป: คะแนน 0-100 คำแนะนำ รายการวิกฤต งบประมาณ แผนงานแบ่งระยะ สรุปตามห้อง
- ส่งออก CSV สำรอง JSON พิมพ์/บันทึก PDF คัดลอกสรุป

## วิธีรัน
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้
2. ไปที่ Settings > Pages เลือก Branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
3. รอสักครู่ แล้วเปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

หรือใช้คำสั่ง
```
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

## เกณฑ์คะแนน
- น้ำหนักหมวด: โครงสร้าง 3, ไฟฟ้า 2.5, ความชื้น/ปลวก 2.5, หลังคา 2, ประปา 2, ผนัง/พื้น 1, ประตูหน้าต่าง 1, ภายนอก 1
- สัดส่วนความรุนแรง: ดี 0, เล็กน้อย 0.2, ต้องซ่อม 0.55, วิกฤต 1
- คะแนน = 100 - (ผลรวมน้ำหนัก x ความรุนแรง / ผลรวมน้ำหนักของรายการที่ตรวจ) x 100
- ช่วงผล: 80 ขึ้นไป ดี, 60 ขึ้นไป ปานกลาง, 40 ขึ้นไป ทรุดโทรมมาก, ต่ำกว่า 40 ควรตรวจเชิงลึก
- ถ้าโครงสร้างหรือไฟฟ้ามีรายการวิกฤต ระบบแนะนำให้หยุดและให้วิศวกรตรวจ
- เงินสำรองค่าใช้จ่ายไม่คาดคิด 15%

น้ำหนัก สัดส่วน และเงินสำรองเป็นค่าตั้งต้นที่ผู้พัฒนากำหนดเอง ยังไม่ได้อ้างอิงมาตรฐานวิศวกรรมหรือผ่านการตรวจสอบจากผู้เชี่ยวชาญ ปรับได้ในโค้ด (ตัวแปร `CATS` และ `PEN`)

## ข้อจำกัด
- เป็นการคัดกรองเบื้องต้น ไม่แทนการตรวจโดยวิศวกรหรือสถาปนิกที่ได้รับใบอนุญาต
- ตรวจไม่ครบ คะแนนอาจสูงเกินจริง (ระบบแจ้งจำนวนรายการที่ยังไม่ตรวจ)
- ค่าซ่อมผู้ใช้กรอกเอง ไม่มีฐานราคากลาง
- ยังไม่มีระบบแชร์โครงการข้ามบัญชี และยังไม่ได้ทดสอบกับผู้ใช้จริง
- โหมดเครื่องนี้ไม่ซิงก์ข้ามเครื่อง และไม่ปลอดภัยพอสำหรับข้อมูลลับบนเครื่องที่ใช้ร่วมกัน
- ทำสำเนาโครงการและนำเข้า JSON ไม่รวมรูปถ่าย
